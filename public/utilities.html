📖 About Snapshots

When you trigger a dataset collection (like collecting a profile or searching for jobs), the API returns a snapshot_id. This ID can be used to retrieve the actual data once the collection is complete.

Typical Workflow:

  1. Trigger a dataset collection using any of the API endpoints
  2. Copy the snapshot_id from the response
  3. Wait a few moments for data collection to complete
  4. Use this page to retrieve the full results
Example Response: 
{
  "success": true,
  "data": {
    "snapshot_id": "abc123xyz789"
  }
}
